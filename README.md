Eigenständige Windows-Desktop-App (Lastenheft-Phase) des Fan-Tools „The Division 2 – Build Optimizer" (Redesign der Web-App [division2-build-optimizer](https://github.com/ApexSHD/division2-build-optimizer)).

The Division 2 ist eine Marke von Ubisoft Entertainment. Diese Anwendung ist ein Fan-Werkzeug und steht in keiner Verbindung zu Ubisoft.
